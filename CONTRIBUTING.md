# Como contribuir

Obrigada por considerar uma contribuição para o **Extrator Automático de ZIP**.

## Antes de começar

- Confira se já existe uma issue ou pull request sobre a mesma ideia.
- Para bugs, descreva a versão do Windows e do Python utilizados.
- Nunca inclua arquivos pessoais, caminhos sensíveis, credenciais ou ZIPs privados nos exemplos.

## Fluxo recomendado

1. Crie uma branch a partir de `main`.
2. Faça uma alteração pequena e objetiva.
3. Teste o fluxo afetado no Windows.
4. Explique no pull request o problema, a solução e como a alteração foi validada.

## Boas contribuições

- correções de bugs;
- melhorias de segurança na manipulação de arquivos;
- mensagens de erro mais claras;
- testes e documentação;
- melhorias de acessibilidade e experiência de uso;
- compatibilidade com novas versões do Python e do Windows.

## Princípios do projeto

O aplicativo deve continuar simples, previsível e seguro. Mudanças que removam a preservação do ZIP original, sobrescrevam dados sem confirmação ou reduzam as validações de segurança não devem ser incorporadas.
